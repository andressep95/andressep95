### SQLift - JPA Class Generator from Postgres DDL
A CLI tool that processes Postgres DDL files to automatically generate JPA entity classes.

**Key Features:**
- Native executables for Mac/Linux (built with GraalVM)
- Docker container support
- Custom template engine for code generation
